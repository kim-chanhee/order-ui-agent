# 사용자 실험 자료

실험에 사용한 참여 안내문과 사용자가 제공한 분석 결과표를 보관합니다. 2026년 10월 25일 Google Drive에서 받은 Word 파일을 원본 그대로 저장하고, GitHub에서 바로 읽을 수 있도록 Markdown 열람본을 함께 제공합니다.

| 자료 | GitHub 열람본 | Word 원본 |
|---|---|---|
| 실험 참여 안내 · 배송 데이터 분석 가이드 V2 | [안내문과 과제](participant-guide-v2.md) | [participant-guide-v2.docx](originals/participant-guide-v2.docx) |
| A2UI 사용자실험 논문용 결과표 | [분석 결과표](study-results.md) | [study-results.docx](originals/study-results.docx) |

안내문에는 약 30분의 진행 절차, 최근 60일 배송 실패 조회 과제, 최근 90일 고객별 배송 실패율 분석 과제와 완료 기준이 포함됩니다. 결과표에는 참가자 구성, 측정도구 신뢰도, 기술통계, 상관분석, 이원분산분석, 행동 로그 및 완료율 집계가 포함됩니다.

## 자료를 읽는 순서

1. [실험 참여 안내](participant-guide-v2.md)에서 과제와 진행 조건을 확인합니다.
2. [분석 노트북 안내](../../Data/A2UI/README.md)에서 분석 순서와 필요한 입력 자료를 확인합니다.
3. [제공된 결과표](study-results.md)를 아래 확인 사항과 함께 읽습니다.
4. 시스템 구현과 평가 흐름은 [시스템 상세 설명](../system-guide.md#연구-평가-절차)을 참고합니다.

## 원본과 열람본

Word 원본의 바이트를 변경하지 않았습니다. 원본 제목·출처 URL·파일 크기·SHA-256 체크섬은 [sources.json](sources.json)에 기록했습니다. Google Drive 문서가 이후 수정되더라도 이 폴더는 위 날짜의 스냅샷입니다.

Markdown은 원문의 본문 순서, 수치, 표 9개와 그림 2개를 보존하고 제목·목록·표 서식을 GitHub에 맞췄습니다. 병합된 표 머리글은 한 행으로 펼쳤으며 Word의 페이지 배치와 글꼴은 원본에서 확인할 수 있습니다. 절·표·그림 번호의 누락이나 원문 표현은 임의로 수정하지 않았습니다. 안내문의 사전·사후 설문 링크는 원문에서도 자리표시자입니다.

## 수정본 반영 사항

사용자가 수정한 Google Drive 결과표를 다시 받아 Word 원본과 Markdown 열람본을 함께 갱신했습니다. 이전 버전에서 표시했던 참가자 구성, PU 계산 예시, 표와 유의성 설명 및 종합 해석의 불일치는 수정본에 반영되어 기존 불일치 안내를 정리했습니다. 이전 보존본은 Git 이력에서 확인할 수 있습니다.

- UI 유형과 AI 리터러시 수준을 교차한 네 집단은 각각 10명으로 설명합니다.
- 표 5와 해석에는 만족도(SAT)·결과 신뢰도·품질(TQ)의 UI 주효과, AI 리터러시 수준의 만족도 효과, 인지부하(CL)의 상호작용이 반영되어 있습니다.
- TQ와 재사용 의도(RI)는 Box–Cox 변환 후 ANOVA 결과이며 나머지 다섯 변수는 원자료 ANOVA 결과임을 명시했습니다.
- SAT의 UI 주효과 p값은 사용자가 확정한 원문 표기 `0.049**`를 그대로 보존합니다. 재계산한 원출력 값은 약 0.0497576378이며, 원문 표기와 원출력 모두 .05 미만입니다.
- 종합 해석은 일부 주관적 평가에서의 차이와 행동지표·완료율에서 유의한 UI 차이가 확인되지 않은 결과를 구분합니다.

분석 절차는 [노트북 실행 순서](../../Data/A2UI/README.md#파일과-실행-순서)를 참고하세요. 원문 7절의 「최종 보고 전 확인 사항」은 그대로 보존했으며, 이번 갱신이 그림·행동 로그 등 모든 항목에 대한 검증 완료를 의미하지는 않습니다.

## 공개 범위

이번 자료는 안내문과 집계 결과 문서입니다. 참가자 명단, 개인별 설문 응답, 개별 대화·행동 로그, 원본 DB는 포함하지 않습니다. 제공 결과표는 연구 기록의 보존본이며 원자료를 통한 독립 재현이나 검증 완료를 뜻하지 않습니다.
