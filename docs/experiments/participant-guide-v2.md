# 실험 참여 안내: 배송 데이터 분석 가이드

AI 챗봇으로 주문·배송 데이터를 분석하며 인터페이스의 사용성과 상호작용을 평가하는 실험입니다.

- **소요 시간:** 약 30분
- **진행 순서:** 사전 설문 → 배정된 순서로 두 과제 수행 → 사후 설문
- **과제 1:** 최근 60일의 배송 실패 주문 수와 해당 물품 확인
- **과제 2:** 최근 90일의 배송 실패율이 가장 높은 고객과 해당 고객의 배송 실패·최종 미수령 물품 확인
- **기간 기준:** 실험 당일이 아닌 데이터셋의 가장 최근 날짜
