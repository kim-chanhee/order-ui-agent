# 사용자 실험 자료

프롬프트 방식(Baseline)과 분석 계획을 검토하는 A2UI 방식의 사용자 경험을 비교한 실험 자료입니다. 실험 참여 안내문과 분석 결과표를 Word 파일 및 GitHub에서 읽을 수 있는 Markdown 문서로 제공합니다.

## 자료 구성

| 자료 | 주요 내용 | GitHub에서 읽기 | Word 파일 |
|---|---|---|---|
| 실험 참여 안내 · 배송 데이터 분석 가이드 V2 | 진행 절차, 챗봇 사용 방법, 수행 과제와 완료 기준 | [실험 참여 안내](participant-guide-v2.md) | [안내문 다운로드](originals/participant-guide-v2.docx) |
| A2UI 사용자실험 논문용 결과표 | 참가자 구성, 설문 분석, 행동 로그 및 과제 완료율 | [분석 결과표](study-results.md) | [결과표 다운로드](originals/study-results.docx) |

## 실험 진행과 과제

실험은 안내문 확인 → 사전 설문 → 배정된 순서에 따른 두 과제 수행 → 사후 설문 순으로 진행하며, 예상 소요 시간은 약 30분입니다. 과제의 ‘최근 60일’과 ‘최근 90일’은 데이터셋에 기록된 가장 최근 날짜를 기준으로 계산합니다.

| 과제 | 확인할 내용 | 완료 기준 |
|---|---|---|
| 과제 1 · 최근 60일 배송 실패 조회 | 배송 실패 주문 수와 실패가 발생한 물품 | 주문 수와 해당 물품을 모두 확인 |
| 과제 2 · 최근 90일 고객별 배송 실패율 분석 | 고객별 전체 주문 수·실패 주문 수·실패율 및 실패율이 가장 높은 고객 | 해당 고객과 배송 실패 물품, 최종적으로 받지 못한 물품 내역까지 확인 |

질문 방식, 대화창 유지, 완료 보고 등 세부 진행 방법은 [실험 참여 안내](participant-guide-v2.md)에 설명되어 있습니다.

## 결과표 읽기

참가자는 총 40명이며, UI 유형(A2UI/Baseline)과 사전 AI 리터러시 수준(낮음/높음)을 교차한 네 집단은 각각 10명입니다. AI 리터러시 수준은 사전 6문항 평균 6.0을 기준으로 구분합니다.

| 결과표 구역 | 살펴볼 내용 |
|---|---|
| 1. 참가자 구성 및 측정도구 검증 | 집단별 인원과 척도의 Cronbach’s α |
| 2. 사후설문 기술통계 | UI 유형 및 AI 리터러시 수준별 평균·표준편차 |
| 3. 사후설문 변수 간 상관관계 | 사용자 평가 변수 사이의 Pearson 상관계수 |
| 4. 이원분산분석 | UI 유형·AI 리터러시 수준의 주효과와 상호작용 |
| 5. 행동 로그 분석 | 수행시간, 프롬프트 수, 과제 유형별 차이와 최종 완료율 |
| 6. 종합 해석 | 사후설문과 행동지표 결과의 종합 설명 |
| 7. 최종 보고 전 확인 사항 | 분석 방법·로그 집계·완료 판정·그림에 관한 점검 항목 |

사후설문에서는 지각된 유용성(PU), 사용 용이성(PEU), 전반적 만족도(SAT), 인지부하(CL), 결과 신뢰도·품질(TQ), 상호작용 품질(IQ), 재사용 의도(RI)를 다룹니다. 인지부하는 점수가 낮을수록 부담이 적다는 의미입니다. TQ와 RI는 Box–Cox 변환 후 ANOVA 결과이며, 나머지 다섯 변수는 원자료 ANOVA 결과입니다.

행동 로그의 수행시간과 프롬프트 수 기술통계는 참가자별 두 과제를 합산한 값입니다. 과제별 차이를 검정하는 분석은 참가자마다 두 과제의 관측값을 사용합니다. 최종 완료율은 두 과제를 모두 완료한 참가자의 비율입니다.
